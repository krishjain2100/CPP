**FreeBSD 80,000 Connection Benchmark Runbook**

**1. Code Modifications (Prerequisites)**

- **C++ Server:** Added `#include <csignal>` in `main.cpp` for `SIGPIPE` and `#include <netinet/in.h>` / `#include <arpa/inet.h>` for BSD socket structures. Used `setsockopt()` to shrink `SO_RCVBUF` and `SO_SNDBUF` to 4096 bytes.
    
- **Python Client:** Added identical `setsockopt()` buffer shrinking to `stess_test.py` before `bind()` and `connect()`, and restricted `source_ips` to `['127.0.0.1', '127.0.0.2', '127.0.0.3', '127.0.0.4']`.


**2. Kernel Tuning (Run as root in Terminal A)** Apply global memory and file limits to the FreeBSD kernel to support 150,000+ total sockets (client + server) in the 2GB VM footprint.

Bash

```
# Expand socket and network memory limits
sysctl kern.ipc.nmbclusters=160000
sysctl kern.ipc.maxsockets=160000

# Expand file descriptor ceilings
sysctl kern.maxfiles=200000
sysctl kern.maxfilesperproc=100000

# Expand accept queue and port ranges
sysctl kern.ipc.soacceptqueue=4096
sysctl net.inet.ip.portrange.first=1024
sysctl net.inet.ip.portrange.last=65535
```

**3. Network Interface Setup (Run in Terminal A)** Generate virtual loopback IPs to bypass the 65,535 ephemeral port limit.

Bash

```
for i in 2 3 4; do ifconfig lo0 alias 127.0.0.$i up; done
```

**4. Native Compilation (Run in Terminal A)** Wipe the macOS binary and compile a native FreeBSD ELF executable using GNU Make.

Bash

```
# Install GNU Make
pkg install -y gmake

# Recompile natively
cd ~/assignment2/build
rm -rf *
cd ..
gmake clean
gmake
```

**5. Execution (Server)** Apply the active shell file limit and boot the matching engine.

Bash

```
cd ~/assignment2/server
ulimit -n 100000
./run-server
```

**6. Execution (Client - Run in Terminal B)** Open a fresh SSH session, apply the same shell limits, and launch the Python stress test.

Bash

```
cd ~/assignment2
ulimit -n 100000
python3 stess_test.py
```
